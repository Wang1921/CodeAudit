# 空闲服务器未回收问题修复

## 问题描述

**现象**：
- 空闲服务器超过700秒仍未被回收
- 日志显示"可回收"但实际未执行回收

**日志证据**：
```
[INFO] /home/CodeAudit/dummy_project/processor-service 空闲 714.0秒，可回收
[INFO] /home/CodeAudit/dummy_project 空闲 447.6秒，可回收
[INFO] /home/CodeAudit/dummy_project/user-service 空闲 344.9秒，可回收
```

## 问题根因

**位置**：`src/server_manager.py:303`

```python
async def evict_idle_servers(self) -> int:
    idle_servers = await self.check_idle_servers()
    
    # 问题：条件过于严格
    if len(self._servers) >= self.max_active_servers and idle_servers:
        # 回收逻辑...
```

**分析**：
- `len(self._servers)` = 3（实际运行的服务器）
- `max_active_servers` = 5（默认配置）
- 条件 `3 >= 5` → **False**
- 结果：即使服务器空闲700多秒，也不会回收

**触发条件**：
- 只有当 `len(self._servers) >= max_active_servers` 时才回收
- 如果微服务数量 < 5，永远无法触发回收

## 解决方案

### 实施修改

#### 1. 修改 `src/server_manager.py`

**新增 `force` 参数**：

```python
async def evict_idle_servers(self, force: bool = False) -> int:
    """
    回收空闲服务器（智能回收策略）
    
    Args:
        force: 是否强制回收（即使未达上限），用于无任务时主动清理
    """
    idle_servers = await self.check_idle_servers()
    
    # 改进：支持强制回收模式
    # - force=True: 无任务时主动清理
    # - force=False: 只在达到上限时回收
    should_evict = force or (len(self._servers) >= self.max_active_servers and idle_servers)
    
    if should_evict and idle_servers:
        # 回收逻辑...
```

#### 2. 修改 `src/engine.py`

**主循环中调用强制回收**：

```python
if not task_pairs:
    # 无任务时强制回收空闲服务器
    # 即使未达到 max_active_servers，也回收长时间空闲的服务器
    evicted = await self.server_manager.evict_idle_servers(force=True)
    if evicted > 0:
        logging.info(f"[主循环] 强制回收了 {evicted} 个空闲服务器")
    await asyncio.sleep(1)
    continue
```

---

## 行为说明

### 正常情况（有任务时）
```
有新任务 → 优先复用空闲服务器 → 不回收
```

### 空闲情况（无任务时）
```
无任务 → 检查服务器状态 → 空闲 > 60s → 强制回收
```

### 达到上限时
```
尝试启动新服务器 → 达到上限 → 触发回收
```
