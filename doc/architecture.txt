Data Flow:
───────────
1. User Input → Coordinator → Python Engine
2. Python Engine triggers SemgrepScanner
3. SemgrepScanner finds routes & sinks → A2A Bus
4. A2A Bus dispatches to LogicAuditor & ReverseTracer
5. Agents output → A2A Bus → Python Engine
6. Python Engine routes to RedValidator & BlueValidator
7. Final results → ReportGenerator → reports/ directory

Key Features:
─────────────
✓ Dual-Track: Bottom-up (Sinks) + Top-down (Routes)
✓ Cross-Service Tracing: Automatic service boundary detection
✓ Adversarial Validation: Red Team vs Blue Team
✓ HTTP Sandbox Pool: LRU cache, max 5 concurrent
✓ Dynamic Prompt Loading: From prompts/core/*.yaml
✓ A2A File System Bus: Atomic operations, fault tolerance
✓ Web Real-time Dashboard: Vue.js at port 8080
