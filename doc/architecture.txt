Data Flow
─────────
1. Engine boots → discovers microservices → runs SemgrepScanner once.
2. Semgrep emits routes + sinks → engine writes one TaskRequest per item.
3. ReverseTracer / LogicAuditor analyze; on hit → VulnCandidate to RedValidator.
4. Red → Blue → ReportGenerator; each step routed by StateRouter.
5. Cross-service signals trigger relay ReverseTracer in every microservice cwd.

Key Properties
──────────────
✓ Dual-Track:           sinks (bottom-up) + routes (top-down)
✓ Adversarial:          Red vs Blue eliminates SAST false positives
✓ Pool reuse:           per-cwd OpenCode HTTP sandbox, LRU + idle eviction
✓ Prompts in YAML:      prompts/core/*.yaml, 6 templates
✓ FS-as-bus:            atomic tmp+fsync+rename writes, fault-tolerant
✓ Live dashboard:       Vue.js, port 8080
